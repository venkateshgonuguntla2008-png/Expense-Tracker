# Expense Tracker

## Overview

Expense Tracker is a Python-based mini project developed to help users record, organize, and analyze their daily expenses. The application allows users to add expenses, view expense history, calculate total spending, and generate category-wise reports. All expense data is stored in a JSON file, ensuring that records are saved for future use.

This project was developed as part of the Python Programming Mini Project for the First Year B.Tech curriculum.

---

## Features

- Add new expenses with category and amount
- View all recorded expenses
- Calculate total spending
- Generate category-wise expense reports
- Store data permanently using JSON files
- User-friendly menu-driven interface

---

## Technologies Used

- Basic Data Structures (Lists and Dictionaries)

## How It Works

1. The user selects an option from the menu.
2. Expense details are entered and stored.
3. Data is saved in a JSON file.
4. Users can view expenses and analyze spending patterns.
5. Reports are generated based on expense categories.
